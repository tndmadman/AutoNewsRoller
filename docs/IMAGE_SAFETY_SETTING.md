# Master automatic content scanning toggle

The single dashboard control applies to all automatic NudeNet and OpenNSFW2 calls (still images, worker final MP4, controller final MP4, and automatic scanner health checks) for new claims. OFF does not change ComfyUI, normal rendering, integrity audit, normal upload, or the completed-video archive. The archive records NOT_SCANNED and a content hash; it does not create an approval or make the video eligible for posting. Existing editorial restrictions, media integrity checks and export authorization remain in force. Existing claims retain their original snapshots. Both components must be updated; old workers cannot claim new OFF jobs. Previous image toggle state is reused; the old diagnostic draft API remains distinct for backwards compatibility, not a dashboard control. Existing isolated drafts remain unchanged.
